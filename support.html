FAQ & Knowledge Base

What does BriefIQ actually do?

Paste a client brief and BriefIQ diagnoses it before prescribing: quality score, red flags, the real problem, insights, strategic territories, scored ideas, cultural intelligence for your market, production planning and media strategy — then exports it all as client-ready documents.

Does it work offline?

Yes — the built-in strategy engine runs entirely in your browser with no internet. Only the optional live AI models (ChatGPT, Claude, Gemini) and Google Docs export need a connection.

Do I need an AI subscription or API key?

No. The built-in engine needs nothing. If you want live AI models, bring your own API key (stored only in your browser) — or use Manual Mode: copy the Master Prompt into any AI you already use and paste the answer back. Manual Mode always works.

How does the Free plan work?

3 full projects per month with every analysis engine included — brief analysis, cultural insights, challenge mode, opportunity gaps. Pro ($20/month) removes the limit and unlocks project memory, production planning, media strategy and advanced exports.

Where is my data stored?

On your device. Projects, settings, API keys and your learning profile live in your browser's local storage and never reach a BriefIQ server (there isn't one). Clearing browser data erases them — export anything you need to keep.

Which markets does the Cultural Insight Engine cover?

Deep packs for Kenya, Nigeria, Ghana, South Africa, Egypt, UAE, India, Indonesia, Japan, UK, Germany, US, Brazil and Mexico — each with regional, continental and global layers. Custom markets get the global layer plus your own inputs.

My exported Word/PowerPoint file looks odd?

Word files open in Word, Google Docs and Pages. The slides file is an outline: in PowerPoint use File → Open and each heading becomes a slide; in Keynote/Google Slides import it as an outline. For pixel-perfect decks, export PDF.

Claude/Anthropic says "network/CORS error"?

Browsers sometimes block direct calls to api.anthropic.com — it's not your key. Use Manual Mode (⧉ Master Prompt) as the reliable path, or try ChatGPT/Gemini keys which allow browser calls.

Can my team share projects?

Not yet — team workspaces are on the roadmap and need our hosted version. Today you can share any analysis as a read-only file or PDF from Export → Share.

How do I install the app?

On Android/desktop Chrome: use the ⬇ Install link in the menu or the browser's install prompt. On iPhone/iPad: Safari → Share → "Add to Home Screen". The installed app opens without browser chrome and works offline.

Refunds & cancellation?

Cancel anytime — no lock-in. If BriefIQ didn't deliver in your first 14 days on a paid plan, email and you'll get a refund, no interrogation.
